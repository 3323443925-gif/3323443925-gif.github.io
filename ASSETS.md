# ASSETS

Third-party assets used in this site. Everything else is drawn in code (WebGL mesh
gradient with a CSS radial-gradient fallback, hand-written SVG logo mark and favicon,
code-drawn wordmarks, generative SVG covers, HTML/SVG panels). There are no
third-party images; the two video posters in `public/videos/` are self-made screenshots
of my own demo videos, and all text content is original.
